隐私政策

适用应用：Qwenpaw  ·  生效日期：2026 年 9 月 15 日  ·  最近更新：2026 年 9 月 15 日

1. 适用范围

Qwenpaw（下称"本应用"）是一个个人自用工具，仅在拥有者本人的私有服务器上运行，且仅访问拥有者本人授权的 Google 账号。本应用没有其他用户，不提供公开服务。

2. 访问哪些 Google 数据

经账号拥有者通过 Google OAuth 同意后，本应用访问其 Gmail 账号中的以下数据：

  • 邮件标题、正文、收发件人、时间等元数据
  • 邮件标签、已读状态
  • 邮件附件的基本信息（文件名、类型、大小）

请求的权限范围（OAuth scope）限于 Gmail 相关范围，不涉及 Google 云端硬盘、日历、联系人、照片等其他 Google 服务。

3. 数据用途

上述数据仅用于：

  • 生成收件箱每日摘要与分类
  • 从邮件中提取待办事项
  • 起草回复草稿（发送前由拥有者本人确认）

数据不会被用于广告投放、不会用于训练通用模型、不会被出售，也不会用于上述目的之外的任何其他用途。

4. 数据存储

邮件处理过程在拥有者本人的私有服务器上完成。OAuth 访问令牌以文件形式保存在该服务器本地文件系统中，仅拥有者本人可读取。本应用不向自己运营的任何服务器上传或留存邮件副本。

5. 第三方共享

为完成摘要与草稿生成，部分邮件文本会通过加密连接（HTTPS）传输给拥有者本人选定的大语言模型 API 服务商进行处理，传输内容限于完成该处理所必需的文本。除此之外，除法律明确要求外，本应用不与任何第三方共享 Google 用户数据。

本应用对 Google API 所获取信息的传输遵循 Google API Services User Data Policy，包括其中的 Limited Use（有限使用）要求。

6. 数据保留与删除

邮件原文不做长期留存；每日生成的摘要会随任务周期滚动覆盖。拥有者可随时通过下方邮箱要求删除全部本地缓存与令牌数据，收到请求后 7 日内完成删除。

7. 撤销授权

拥有者可随时访问 myaccount.google.com/permissions 撤销本应用的访问权限。撤销后，本应用将立即无法读取该账号的任何数据。

8. 安全

所有与 Google API 的通信均使用 HTTPS。访问令牌受服务器操作系统文件权限保护，不写入日志，不随代码公开。

9. 政策变更

本政策如有更新，将直接反映在本页面并更新"最近更新"日期。

Privacy Policy (English)

Qwenpaw is a personal-use tool that runs on its owner's own private server and accesses only the Google account of its owner. It has no other users and offers no public service.

Data accessed. With the owner's explicit OAuth consent, the app reads the owner's Gmail messages (headers, body, senders, labels, read state, and attachment metadata). No other Google services are accessed.

How data is used. Solely to produce daily inbox summaries and classification, extract action items, and draft replies for the owner to review. Data is never used for advertising, never used to train general-purpose models, never sold, and never used for any other purpose.

Storage. Processing happens on the owner's private server. OAuth tokens are stored as a file on that server, readable only by the owner. No copy of the mailbox is uploaded to any server operated by the developer.

Third parties. To generate summaries and drafts, excerpts of email text may be sent over HTTPS to the large-language-model API provider selected by the owner, limited to what is necessary for that processing. Other than that, and except where legally required, Google user data is not shared with any third party.

Retention and deletion. Raw email content is not retained long-term; daily summaries roll over. The owner may request deletion of all local cached data and tokens by email; deletion is completed within 7 days.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Limited Use. Qwenpaw's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
