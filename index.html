Qwenpaw

个人自用的邮件自动化助手 · A personal-use email automation assistant

这是什么

Qwenpaw 是一个个人自用的自动化助手程序，运行在拥有者本人的家庭服务器（NAS）上。经拥有者本人通过 Google OAuth 明确授权后，它访问拥有者自己的 Gmail 账号，用于：

  • 汇总与分类收件箱邮件，生成每日摘要
  • 从邮件中提取待办事项并提醒拥有者
  • 起草回复草稿，发送前由拥有者本人确认

本程序不面向公众提供服务，不开放注册，不收集任何其他人的数据。

About (English)

Qwenpaw is a personal-use automation assistant that runs on its owner's own home server (NAS). With the owner's explicit OAuth consent, it accesses the owner's own Gmail account in order to summarize and classify incoming mail, surface action items, and prepare draft replies for the owner's review.

It is not a public service. There is no sign-up, no other users, and no data is collected from anyone else.
